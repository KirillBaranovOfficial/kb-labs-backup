## Установка и первая команда

Требования: версия Node.js должна соответствовать единственной основной
версии, указанной в `engines.node` корневого `package.json`; также требуется
не менее 1,20 ГиБ доступной памяти и 2 ГиБ свободного места на диске.
Установщик сам управляет pnpm и печатает точную команду переключения, если
текущая основная версия Node.js не поддерживается.

```bash
curl -fsSL https://kblabs.ru/install.sh | sh
kb-create install
```

Выберите локальный доступ для работы только с этого компьютера или защищённый
доступ, если пользователям нужно входить в систему. Проверьте установку
командами `kb-create status` и `kb-create doctor`.

Затем выполните команду в любом Git-проекте:

```bash
cd ~/any-project
kb commit
```

`kb commit` работает и без LLM, используя эвристики. Чтобы включить генерацию
через OpenAI, задайте адаптер командами `kb config set --scope platform platform.adapters.llm
@kb-labs/adapters-openai` и
`kb config set --scope platform platform.adapterOptions.llm.apiKey '${OPENAI_API_KEY}'`, затем
экспортируйте `OPENAI_API_KEY` в оболочке.

## Откройте Studio

Откройте Studio по адресу Gateway, который показал установщик. Локальный
доступ открывает интерфейс без входа и доступен только с этого компьютера.
Защищённый режим показывает страницу входа: используйте учётную запись
администратора, созданную при установке.

Зарегистрируйте папку проекта на странице **Projects**. Переключатель активного
проекта в оболочке Studio общий для страниц плагинов, адаптеров, аналитики,
журналов и событий. Карточка на главной странице показывает состояние и
готовность Gateway.
