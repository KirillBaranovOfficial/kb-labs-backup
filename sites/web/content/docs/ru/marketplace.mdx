## Установка плагина в проект

Выполните команду из каталога проекта, указав точную версию:

```bash
kb marketplace install @kb-labs/commit-entry@1.2.3
```

Проект хранит версию и состояние плагина в `.kb/marketplace.lock`. Сам пакет устанавливается в общее хранилище машины. Команда не меняет `package.json`, lock-файл пакетного менеджера или `node_modules`. Добавьте marketplace lock в git вместе с проектом.

Команды `kb marketplace plugins disable <package>` и `kb marketplace plugins enable <package>` выключают и включают плагин для проекта. `kb marketplace uninstall <package>` удаляет его pin.

## Установка и привязка адаптера

Сначала установите адаптер в граф пакетов платформы, затем привяжите его к слоту текущего проекта:

```bash
kb marketplace install @kb-labs/adapters-fs@1.2.3 --scope platform
kb adapter bind storage @kb-labs/adapters-fs
```

Команда bind записывает `platform.adapters.storage` в `.kb/kb.config.json[c]` проекта. Параметры адаптера настраиваются отдельно для проекта командой `kb config set platform.adapterOptions.storage '<json-value>`. В Studio на странице **Plugins** выбранного проекта можно устанавливать, включать, выключать и удалять плагины. На странице **Adapters** можно установить адаптер на машину, привязать его к слоту проекта и настроить параметры.

Привязка отклоняется, если пакет отсутствует в marketplace lock платформы или не распознан как адаптер. В таком случае установите адаптер командой `kb marketplace install … --scope platform`.
