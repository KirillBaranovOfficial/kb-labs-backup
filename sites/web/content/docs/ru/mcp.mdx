title: MCP-сервер проекта
description: Подключение MCP-клиента к инструментам проекта KB Labs через host.
lang: ru
slug: mcp
---

Для каждого зарегистрированного проекта доступна точка Streamable HTTP в его
среде выполнения:

```text
http://127.0.0.1:4000/api/v1/projects/<project-id>/mcp
```

Чтобы узнать идентификатор проекта, выполните `kb project show --json` в его
каталоге. Незарегистрированную папку можно зарегистрировать командой
`kb project add`; команда сохраняет канонический путь и не создаёт файлы в проекте.
Конфигурацию клиента можно вывести командами `kb mcp config claude`,
`kb mcp config codex` или `kb mcp config cursor`.

В локальном режиме запросы принимаются без токена, а host доступен только через
loopback. В защищённом режиме нужен Bearer-токен, выданный gateway. Host выбирает
среду выполнения по идентификатору проекта в URL, поэтому каждая точка доступа
показывает инструменты именно этого проекта. Клиенты используют стандартные
запросы MCP Streamable HTTP: `initialize`, `tools/list` и `tools/call`.
