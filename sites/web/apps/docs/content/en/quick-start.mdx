Install KB Labs, then run your first command in any Git project.

## Prerequisites

- macOS or Linux (Windows installation is not yet supported by this journey).
- Node.js <NodePolicy />.x.
- At least 1.20 GiB available memory and 2 GiB free disk space.
- `curl` to run the installer.

The installer manages its pnpm runtime; you do not need to install pnpm first.

## Install KB Labs

```bash
curl -fsSL https://kblabs.ru/install.sh | sh
kb-create install
```

The first command installs the `kb-create` launcher. The second installs and
starts the platform, checks the setup, and configures the `kb` command. Local
access is the default and accepts connections only from this computer. Choose
secured access during setup if other computers or users need to sign in.

Check the installation and host:

```bash
kb-create status
kb-create doctor
```

## Run your first command

Use any existing Git project (or create one), then run:

```bash
cd ~/any-project
kb commit
```

The commit command works without an LLM; it can use its heuristic path. To
enable AI-backed generation with OpenAI, set the adapter and provide the key
through an environment variable:

```bash
kb config set --scope platform platform.adapters.llm @kb-labs/adapters-openai
kb config set --scope platform platform.adapterOptions.llm.apiKey '${OPENAI_API_KEY}'
export OPENAI_API_KEY=your-openai-api-key
```

## Agent and CI installation

For non-interactive installs, provide a release index and use the JSON apply
operation. Replace the index path with the sealed index for the release you
intend to install:

```bash
kb-create apply --json --index ./release-index.json \
  --platform-root ./ci-platform --service-profile default \
  --scenario commit
```

## Troubleshooting

| Error code | What happened | Fix |
| --- | --- | --- |
| `KB_NODE_VERSION_UNSUPPORTED` | Node.js is on a major outside the supported policy. | Run the version-switch command shown in the diagnostic, then retry `kb-create install`. |
| `KB_INSTALL_MEMORY_INSUFFICIENT` | Less than 1.20 GiB memory is available. | Close memory-heavy applications or increase machine memory, then rerun `kb-create install`. |
| `KB_INSTALL_NO_DISK_SPACE` | Less than 2 GiB is free for installation. | Free disk space or choose a writable platform directory with `kb-create install --platform-root PATH`. |
| `KB_INSTALL_PACKAGE_MANAGER_KILLED` | The package manager was killed, likely because memory ran out. | Free memory, then rerun `kb-create install`. |
| `KB_INSTALL_PORT_IN_USE` | A port needed by the platform is occupied. | Stop the process using the reported port, then rerun `kb-create install`. |

More help: [Guides → Troubleshooting](/guides/troubleshooting)
