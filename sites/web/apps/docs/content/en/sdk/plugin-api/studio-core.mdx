Core components cover common actions and compact content surfaces. Components that expose a size use the shared `sm`, `md`, and `lg` scale.

<UiKitPreview name="buttons" />

```tsx
import { UIButton } from '@kb-labs/sdk/studio';

<UIButton size="sm" variant="primary">Save</UIButton>
<UIButton size="md">Cancel</UIButton>
<UIButton size="lg" variant="primary">Continue</UIButton>
```
