Plugin pages can use the Studio UI kit through `@kb-labs/sdk/studio`. The same components power Studio itself, so plugin interfaces follow the host theme and shared interaction patterns.

<Callout type="info">
Import UI components from `@kb-labs/sdk/studio` in plugin pages. This is the supported plugin boundary; do not import Studio application internals.
</Callout>

## Component categories

The component inventory and category links are generated from the UI kit's public exports during the normal build. Choose a category to browse its components and interactive examples.

Recipes stay hand-curated and task-oriented. See the [Studio UI cookbook](/sdk/plugin-api/studio-cookbook) for copyable patterns.
