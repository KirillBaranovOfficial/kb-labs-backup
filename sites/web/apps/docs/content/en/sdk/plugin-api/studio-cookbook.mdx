These examples combine public UI kit components into practical page patterns. The cookbook is intentionally flat: use the table of contents to jump to a recipe, and use the component catalog pages for API discovery.

## Action choice

Use a segmented control when a small set of options changes the current view. Use buttons for actions that commit a change.

```tsx
import { UIButton, UISegmented } from '@kb-labs/sdk/studio';

function ViewToolbar() {
  return (
    <div className="toolbar">
      <UISegmented
        size="sm"
        defaultValue="Overview"
        options={['Overview', 'Activity', 'Settings']}
      />
      <UIButton size="sm" variant="primary">Create</UIButton>
    </div>
  );
}
```

## Page sections with route sync

Use underline tabs for a plugin page with distinct sections. URL sync is opt-in, so tabs remain local by default.

```tsx
import { UITabs } from '@kb-labs/sdk/studio';

function GatewayPage() {
  return (
    <UITabs
      variant="underline"
      size="md"
      syncUrl="search"
      items={[
        { key: 'overview', label: 'Overview', children: <Overview /> },
        { key: 'auth', label: 'Authentication', children: <Authentication /> },
      ]}
    />
  );
}
```
