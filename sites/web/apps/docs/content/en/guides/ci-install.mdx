Use `kb-create apply --json` for a non-interactive install. It applies the
request described by a sealed release index and prints machine-readable
results for CI or an agent to inspect.

## Apply a release index

Make the release index available to the job, then provide its path and an
installation root:

```bash
kb-create apply --json --index ./release-index.json \
  --request-platform-root ./ci-platform --service-profile default \
  --scenario commit
```

The example uses the `commit` scenario from the installer journey. Replace the
index path with the sealed index for the release you intend to install. The
launcher validates the index digest, package requirements, and compatibility
relations before writing packages. A failed operation returns a non-zero exit
status and a structured error in the JSON output.

For a prepared request, pass the request file to the same operation:

```bash
kb-create apply --json --index ./release-index.json \
  --input ./install-request.json
```

## Inspect or remove the installation

```bash
kb-create status --platform-root ./ci-platform --json
kb-create doctor --platform-root ./ci-platform --json
kb-create uninstall --platform-root ./ci-platform
```

The `--json` flag makes status and doctor suitable for automation. Keep the
platform root isolated to the job or runner so uninstall cannot affect a
shared installation.

## Installation prerequisites and recovery

The launcher requires Node.js 24.x, 1.20 GiB available memory, and 2 GiB free
disk. It manages pnpm itself. If an install fails with one of these codes:

| Error code | Recovery |
| --- | --- |
| `KB_INSTALL_NODE_VERSION` | Install Node 24, then rerun apply; with nvm: `nvm install 24 && nvm use 24`. |
| `KB_INSTALL_MEMORY_INSUFFICIENT` | Free memory or use a runner with more memory, then rerun apply. |
| `KB_INSTALL_NO_DISK_SPACE` | Free disk space or move `--request-platform-root` to a filesystem with at least 2 GiB free. |
| `KB_INSTALL_PACKAGE_MANAGER_KILLED` | Free memory or use a larger runner, then rerun apply. |
| `KB_INSTALL_PORT_IN_USE` | Release the port identified in the error and rerun apply. |

See [Installation](/installation) for the interactive local flow and the
complete installation error table.
