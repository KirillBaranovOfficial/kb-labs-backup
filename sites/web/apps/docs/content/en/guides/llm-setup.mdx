The KB Labs install journey does not require an LLM. `kb commit` works without
one by using its heuristic path. Configure an adapter when you want an
AI-backed feature and have credentials for a provider.

## Configure OpenAI

After installing KB Labs, set the adapter and reference the API key through an
environment variable:

```bash
kb config set platform.adapters.llm @kb-labs/adapters-openai
kb config set platform.adapterOptions.llm.apiKey '${OPENAI_API_KEY}'
export OPENAI_API_KEY=your-openai-api-key
```

Replace `your-openai-api-key` with your key. Keep it in your shell environment
or secret manager; do not commit it to the repository. `kb config set` writes
the project configuration by default.

## Verify the setup

In a Git project, run:

```bash
cd ~/any-project
kb commit
```

The command's output identifies whether generation used the LLM or the
heuristic path. If it reports heuristics, check that `OPENAI_API_KEY` is set
in the same shell and that the configured adapter package is installed.

See [Configuration → kb.config](/configuration/kb-config) for config scopes
and [Adapters](/adapters) for the available providers.
