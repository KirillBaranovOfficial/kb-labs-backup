## Goal

As a tooling operator, inspect and clean up supervised command trees, including when the invoking supervisor exits unexpectedly, so hung or orphaned work is visible and does not outlive its owner.

## Preconditions

From the workspace root, set `TMP` to a fresh temporary directory, then build
`proc-helper` with `(cd tools/clikit && go build -o "$TMP/proc-helper"
./proc/testhelper)` and `kb-runner` with `(cd tools/kb-runner && go build -o
"$TMP/kb-runner" .)`. Set `STATE="$TMP/state"`, `OUT="$TMP/stdout.log"`, and
`ERR="$TMP/stderr.log"`. The fixture's `detached` and `double-fork` commands
create detached descendants and record their PID in a file when asked.
Every command that needs a temp file, output path, state directory, or minimum
free-space value obtains those values from the fresh `TMP` directory. Linux and
macOS are supported; Windows is unsupported.

## Pass criteria

The shared supervisor owns the command tree independently from the invoking process. Live state and event records use the caller-selected state directory. Linux and macOS behavior is tested; Windows is explicitly unsupported. On macOS, the keeper samples ancestry every 100 ms and remembers observed descendants by PID and start identity; it also uses the inherited run marker when `kern.procargs2` exposes it. Membership requires current ancestry, recorded ancestry history with matching PID/start identity, or a readable run marker. A descendant created and reparented entirely between sampling instants with no readable marker remains outside the macOS guarantee and is not classified as owned. `Unverified` describes a process connected to recorded ownership history whose identity/ownership observation failed; it is never signalled. Slot admission uses the run registry and a shared state lock; gates are held by keeper identity; disk waits and queue states remain visible in `ps` and JSONL.
